# keyon's blog

A plain static journal site served by GitHub Pages straight from `main` (no framework, no npm).
The home page shows the newest entry and, below it, every entry from that entry's week (Monday to Sunday).
The menu button in the top bar lists the sections; a section page lists all of its entries by month.

## Files

- `entries/YYYY/MM/YYYY-MM-DD-short-title.md`: one journal entry (markdown with front matter)
- `sections.json`: the sections, in menu order
- `entries.json`: generated by `build.py` from the two above. Never edit it by hand.
- `index.html`, `style.css`, `app.js`: the site. `vendor/marked.min.js` renders markdown in the browser.
  After changing `style.css` or `app.js`, bump the `?v=` number on their links in `index.html` so browsers drop cached copies.
- `README.md` must stay exactly `keyons blog`.

## Adding writing

Keyon sends writing in batches (for example a whole month at once) and says which day and section each piece belongs to.

1. Make one file per day per section, named `entries/YYYY/MM/YYYY-MM-DD-short-title.md`:

   ```markdown
   ---
   title: A short title
   date: 2026-11-26
   section: digital-design-verification
   ---
   The writing, in markdown.
   ```

   `section` is a slug from `sections.json`. Keep Keyon's words as written; only organize and format them.
   If a piece has no title, write a short plain one from its content.
   If a day has more than one writing ("Writing 2" etc.), add `order: 2`, `order: 3`... to the later ones; the highest order is treated as the newest.
   Images go next to the entry (for example `entries/2026/11/images/eye.png`) and are linked relatively: `![eye](images/eye.png)`.
2. Run `python3 build.py`. It rewrites `entries.json` and fails with a list of problems if any front matter is wrong.
3. Commit and push to `main`. GitHub Pages republishes within a minute or two.

## Adding a section

Add `{ "slug": "...", "name": "..." }` to `sections.json` where it should appear in the menu, then run `python3 build.py`.

## Preview locally

`python3 -m http.server` in this folder, then open http://localhost:8000 (opening `index.html` as a file will not load entries).
